## About

This repository contains dharsi's public-facing documentation, including technical guides, compliance frameworks, AI governance resources, and reference material for regulated industries.

dharsi AI Ltd is an AI software company registered in the Dubai International Financial Centre (DIFC), Dubai. We build enterprise AI platforms for banks and regulated enterprises across the UAE, GCC, and Africa.
